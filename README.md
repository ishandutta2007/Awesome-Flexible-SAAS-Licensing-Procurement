## 📈 Sector Overview & Market Dynamics

The global procurement and SaaS spend management software market reached **$8.67 billion in 2026** (scaling towards $15B+ at ~9.7% CAGR), alongside hyperscaler cloud marketplace GMV projected to surpass **$45 billion in 2026**. 

The sector exhibits a dual structure:
- **Cloud Marketplaces (Winner-Take-Most / Concentrated):** Highly consolidated among the Big Three hyperscalers (Microsoft Azure, AWS, and Google Cloud) which command over 80% of enterprise marketplace transactions, driven by multibillion-dollar cloud commitments (EDP, MACC) and ISV co-sell incentives.
- **SaaS Procurement & License Automation (Moderately Fragmented):** Moderately fragmented with rapid consolidation underway (such as Vertice acquiring Vendr and AppDirect acquiring Tackle.io). Mid-market procurement intelligence, spend optimization, and developer licensing toolchains remain contested between specialized AI-driven platforms and self-hosted open-source engines.

## 🟩 Open-Source Software

Self-hosted, transparent, and community-driven tools for software license management, hardware copy protection, SBOM compliance checking, and cloud service marketplaces. 

Sorted descending by GitHub star count:

- **[aboutcode-org/scancode-toolkit](https://github.com/aboutcode-org/scancode-toolkit)** [![Stars](https://img.shields.io/github/stars/aboutcode-org/scancode-toolkit?style=social&color=white)](https://github.com/aboutcode-org/scancode-toolkit/stargazers)  
  **Stack:** Python | **License:** Apache-2.0 / CC-BY-4.0  
  A comprehensive suite to scan codebases, binaries, and dependencies for open-source licenses, copyright notices, and license compliance obligations. Widely regarded as the industry standard for software composition analysis (SCA) and SBOM compilation.  
  *Best for:* Legal and engineering teams auditing vendor code and third-party software packages.

- **[oss-review-toolkit/ort](https://github.com/oss-review-toolkit/ort)** [![Stars](https://img.shields.io/github/stars/oss-review-toolkit/ort?style=social&color=white)](https://github.com/oss-review-toolkit/ort/stargazers)  
  **Stack:** Kotlin / Java | **License:** Apache-2.0  
  The OSS Review Toolkit (ORT) automates open-source software compliance checks across the software development lifecycle. Verifies dependencies against organizational licensing policies, generates curated SPDX/CycloneDX SBOMs, and integrates into automated CI/CD pipelines.  
  *Best for:* Enterprise compliance automation and automated procurement due-diligence gates.

- **[open-license-manager/licensecc](https://github.com/open-license-manager/licensecc)** [![Stars](https://img.shields.io/github/stars/open-license-manager/licensecc?style=social&color=white)](https://github.com/open-license-manager/licensecc/stargazers)  
  **Stack:** C++ / CMake | **License:** BSD-2-Clause  
  A cross-platform software licensing and node-locked copy-protection library. Generates tamper-resistant hardware identifiers to bind software executables to specific machines, preventing unauthorized copying and unauthorized license distribution.  
  *Best for:* Desktop software developers, embedded software vendors, and on-premises software distributors requiring hardware-locked licensing.

- **[fossology/fossology](https://github.com/fossology/fossology)** [![Stars](https://img.shields.io/github/stars/fossology/fossology?style=social&color=white)](https://github.com/fossology/fossology/stargazers)  
  **Stack:** PHP / C / C++ | **License:** GPL-2.0  
  A battle-tested open-source license compliance engine and web workstation. Runs license, copyright, and export compliance scans from a multi-user web interface with database backing, copyright discovery, and SPDX reporting.  
  *Best for:* Organizations requiring an on-premise compliance review portal for enterprise procurement teams.

- **[google/go-licenses](https://github.com/google/go-licenses)** [![Stars](https://img.shields.io/github/stars/google/go-licenses?style=social&color=white)](https://github.com/google/go-licenses/stargazers)  
  **Stack:** Go | **License:** Apache-2.0  
  A lightweight CLI tool by Google that inspects Go binaries and dependency trees, extracts all library licenses, checks them against allowed license types (forbidden, restricted, notice, permissive), and exports notices.  
  *Best for:* Golang developers and procurement engineers validating distribution compliance before shipping binaries.

- **[tabloy/keygate](https://github.com/tabloy/keygate)** [![Stars](https://img.shields.io/github/stars/tabloy/keygate?style=social&color=white)](https://github.com/tabloy/keygate/stargazers)  
  **Stack:** Go | **License:** AGPL-3.0  
  A self-hosted software license management server designed as an open-source alternative to Keygen, Cryptlex, and LicenseSpring. Features subscriptions, perpetual licenses, floating (concurrent) seat limits, atomic usage metering, signed offline tokens, and full Stripe integration.  
  *Best for:* Indie developers and SaaS vendors wanting complete control over license keys, entitlements, and telemetry without third-party fees.

- **[waldur/waldur-mastermind](https://github.com/waldur/waldur-mastermind)** [![Stars](https://img.shields.io/github/stars/waldur/waldur-mastermind?style=social&color=white)](https://github.com/waldur/waldur-mastermind/stargazers)  
  **Stack:** Python / Django | **License:** MIT  
  An open-source hybrid cloud orchestrator and procurement marketplace. Features a self-service resource storefront, order management, multi-tenant quota accounting, enterprise approval workflows, and billing/credit tracking for cloud infrastructure.  
  *Best for:* Universities, government cloud operations, and enterprises managing internal multi-cloud service marketplaces.

- **[alvarorg14/openlicensd](https://github.com/alvarorg14/openlicensd)** [![Stars](https://img.shields.io/github/stars/alvarorg14/openlicensd?style=social&color=white)](https://github.com/alvarorg14/openlicensd/stargazers)  
  **Stack:** Go / Nuxt / PostgreSQL | **License:** Apache-2.0  
  A lightweight, self-hosted software licensing server with a modern administrative UI. Provides RESTful activation endpoints, time-based license expiry, OIDC single sign-on, and integration with container registries (like Harbor).  
  *Best for:* Startups and software vendors seeking a clean, turn-key licensing service with minimal setup overhead.

- **[SemClone/mcp-semclone](https://github.com/SemClone/mcp-semclone)** [![Stars](https://img.shields.io/github/stars/SemClone/mcp-semclone?style=social&color=white)](https://github.com/SemClone/mcp-semclone/stargazers)  
  **Stack:** Python / MCP | **License:** Open Source (PyPI)  
  A Model Context Protocol (MCP) server that empowers LLMs and AI coding assistants (Cursor, Claude, VS Code) to perform software license scanning, binary inspections (ELF, PE, Mach-O), vulnerability lookups, and CycloneDX SBOM validation.  
  *Best for:* AI-assisted developer workflows and automated license checks directly within IDEs.

- **[aiexponent/license-compliance-checker](https://github.com/aiexponent/license-compliance-checker)** [![Stars](https://img.shields.io/github/stars/aiexponent/license-compliance-checker?style=social&color=white)](https://github.com/aiexponent/license-compliance-checker/stargazers)  
  **Stack:** Python | **License:** Open Source (PyPI)  
  A license verification and compliance utility for SBOM generation and AI model license detection (OpenRAIL, Llama, Gemma, Mistral). Supports EU AI Act Article 53 evidence generation and training dataset risk identification.  
  *Best for:* AI/ML engineering and compliance officers assessing regulatory and licensing risks in open-source models.
